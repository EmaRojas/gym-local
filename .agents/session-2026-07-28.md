### FASE 1: Rediseño UI/UX Mobile-First (todos los componentes)

#### 1.1 style.css - Base global rediseñada
- `btn-icon`: subió de `w-10 h-10` (40px) a `w-11 h-11` (44px, mínimo Apple HIG)
- Nuevo `btn-icon-sm` de 36px para actions secundarias
- `input-field`: `min-height: 48px`, `font-size: 16px` (previene zoom en iOS)
- Nuevas clases: `input-field-sm`, `select-field`, `label-field`, `error-text`
- Safe areas: `.safe-bottom` y `.safe-top` con `env(safe-area-inset-*)`
- Anti-zoom iOS: `font-size: 16px` en `input, select, textarea, button`
- `overscroll-behavior: none` en html (evita pull-to-refresh)

#### 1.2 App.vue
- Agregado `safe-top` en wrapper, `safe-bottom` en main
- `sm:px-6` para tablets

#### 1.3 ExerciseSetEditor.vue
- Delete button: `w-6 h-6` → `btn-icon-sm` (36px) con hover rojo
- Inputs: `inputmode="decimal"`/`inputmode="numeric"` para teclados correctos
- Labels visibles debajo de cada input ("Peso", "Reps")
- `aria-label` en cada input y botón de eliminar
- `tabular-nums` para números alineados

#### 1.4 ConfirmSheet.vue
- Focus trap: `confirmBtn` se enfoca al abrir con `watch`
- Keyboard: `@keydown.escape` para cerrar
- Accessibility: `role="dialog"`, `aria-modal`, `aria-label`
- Safe area: `safe-bottom` para iPhone
- Botones usan clases `btn-secondary` y focus-visible ring

#### 1.5 HomeView.vue
- Cards con `group` + `group-active:bg-*` para feedback visual
- `leading-tight` en títulos, mayor spacing

#### 1.6 AdminView.vue
- Header buttons: `btn-icon` (44px) en vez de `w-10 h-10`
- Labels con `for`/`id` en todos los campos del formulario
- `autocomplete` en campos de formulario
- `role="alert"` en mensajes de error
- Modal buscador: `items-end` en mobile (bottom sheet), `items-center` en sm+
- Safe area en botón guardar

#### 1.7 AlumnoView.vue
- Gym selector: `<div>` → `<button>` para accesibilidad nativa
- Header buttons: `btn-icon` (44px)
- Exercise cards: avatar `w-11 h-11`, imagen `h-52`, `p-3` en instrucciones

#### 1.8 ExercisesBrowserView.vue

### FASE 2: Campo logo en Admin/Gym

#### 2.1 types.ts
- `Admin.logo?: string` — campo nuevo
- `GymInfo.logo?: string` — campo nuevo

#### 2.2 stores/admin.ts
- Persiste `logo` en localStorage al hacer login

#### 2.3 stores/alumno.ts
- `gymSeleccionado` ahora incluye `logo?: string`
- Nuevo getter `logoGym`
- `_fetchGymName()` lee `data.logo` de Firebase
- Los 3 lugares que arman `GymInfo[]` propagan `logo`
- `_guardarSesion()` guarda `logo` en localStorage
- `restaurarSesion()` restaura `logo` desde localStorage

#### 2.4 AlumnoView.vue
- **Seleccionar gym**: cada card muestra `<img>` con el logo si existe, fallback al ícono genérico
- Nuevo data `logoGym` sincronizado con el store

#### Carga en Firebase
En el doc `admins/{id}` se agrega el campo:
```
logo: "https://..."   // URL de la imagen del logo
```
Si `logo` está vacío o no existe, se usan íconos genéricos.
