### FASE 1: Bugs Críticos

#### 1.1 sync.js - Eliminar subirDatos() duplicado
- Archivo: `src/stores/sync.js`
- `subirDatos()` era idéntico a `sincronizarPersonas()` → eliminado
- `AdminView.vue:461` cambiado: `subirDatos()` → `sincronizarPersonas()`

#### 1.2 sync.js - Eliminar bajarDatos() peligrosa
- Archivo: `src/stores/sync.js`
- `bajarDatos()` hacía `db.personas.clear()` y `db.planes.clear()` borrando datos de todos los admins
- Nunca se usaba externamente (solo `bajarAdmin()` se usaba) → eliminada

#### 1.4 useExercises.js - Estado global compartido
- Archivo: `src/composables/useExercises.js`
- `busqueda`, `filtroCategoria`, `filtroEquipo`, `ejercicioSeleccionado` estaban a nivel de módulo (compartidos entre instancias)
- Movidos adentro de `useExercises()` para que cada componente tenga los suyos
- `exercisesData`, `exercisesLoaded`, `categorias`, `equipos`, `totalEjercicios` se mantienen compartidos (correcto)

#### 1.5 AdminView - Fix iniciales()
- Archivo: `src/views/admin/AdminView.vue`
- `((p.nombre || '')[0] || '' + (p.apellido || '')[0] || '').toUpperCase()` solo mostraba 1 letra
- Fix: `(((p.nombre || '')[0] || '') + ((p.apellido || '')[0] || '')).toUpperCase()`
- Ahora muestra ambas iniciales (ej: "JD")

#### 1.6 AlumnoView - DNI sin filtro numérico
- Archivo: `src/views/alumno/AlumnoView.vue`
- Agregado `@input="dni = dni.replace(/[^0-9]/g, '')"` al input de DNI

#### 1.7 admin.js - Validar sesión restaurada
- Archivo: `src/stores/admin.js`
- Importado `doc, getDoc` de firebase/firestore
- `restaurarSesion()` ahora hace `getDoc` contra Firestore para verificar que el admin existe
- Si no existe → borra localStorage y retorna false
